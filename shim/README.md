# shim

Generated re-exports of typescript-go's internals, so verify can reach them.

## Why this exists

typescript-go keeps its real packages under its own `internal/`, which Go
enforces: nothing outside that module can import them. verify needs
`ast.SkipParentheses`, `checker.Checker`, `tspath.NormalizePath` and a few
hundred other symbols, so `tools/generate_shims` emits a thin package per
subsystem that re-exports them by `//go:linkname`.

Every file here says `// Code generated by tools/generate_shims. DO NOT EDIT.`
and means it. Change the generator, not the output.

## Why the directory is named `shim` and not `typescript_go_shim`

Because the name is not ours. These packages are imported as

    github.com/microsoft/TypeScript/tsc/shim/ast

not `github.com/system-inc/verify/shim/ast`. The directory lives in this
repository and belongs to the vendored module's namespace, which is what
makes the `//go:linkname` references resolve. Renaming it means maintaining a
fork of upstream's module layout, and the ~500 import lines that name it are
the smaller half of that cost.

This file exists because a reader will reasonably wonder, and the directory
name cannot answer.
