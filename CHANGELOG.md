# Changelog

Every release of cohere has a section here, newest first. Versions follow semver, as
[CONTRIBUTING.md](CONTRIBUTING.md#versioning-and-the-changelog) states. Each section lists, per rule
set, every rule turned on or off, every severity and option change, and every other setting that
changed. It's generated by `go run ./internal/release/tools/changelog` from the sets themselves. What
changed in cohere outside the sets is written under the same heading.
